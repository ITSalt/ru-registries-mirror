# ru-registries-mirror

Машиночитаемые копии государственных реестров РФ, снятые с официальных
источников и обновляемые по расписанию.

## Зачем

Часть ведомственных хостов отвечает только с российских адресов:
`reestrs.minjust.gov.ru` и все `*.rkn.gov.ru` из-за рубежа недоступны — DNS
резолвится, соединение сбрасывается. Любой инструмент, работающий не из РФ, не
может проверить упоминание иностранного агента или запрещённой организации
вообще никак.

Это зеркало снимается с машины с российским выходом и выкладывает результат
туда, где он доступен всем.

## Что здесь есть

| Реестр | Файл | Первоисточник |
|--------|------|---------------|
| Реестр иностранных агентов | `data/minjust_foreign_agents.json` | `reestrs.minjust.gov.ru` |
| Перечень нежелательных организаций | `data/minjust_undesirable_orgs.json` | `reestrs.minjust.gov.ru` |
| Перечень организаций, признанных экстремистскими | `data/minjust_extremist_orgs.json` | `minjust.gov.ru` |
| Единый федеральный список террористических организаций | `data/fsb_terrorist_orgs.json` | `fsb.ru` |
| Федеральный список экстремистских материалов | `data/minjust_extremist_materials.json` | `minjust.gov.ru` |

`index.json` — манифест: по каждому реестру количество записей, URL
первоисточника, sha256 его исходных байт, время съёма и статус.

## Как читать

```bash
curl -s https://raw.githubusercontent.com/ITSalt/ru-registries-mirror/main/index.json
curl -s https://raw.githubusercontent.com/ITSalt/ru-registries-mirror/main/data/minjust_foreign_agents.json
```

```python
import json, urllib.request
BASE = "https://raw.githubusercontent.com/ITSalt/ru-registries-mirror/main/"
index = json.loads(urllib.request.urlopen(BASE + "index.json").read())
meta = index["registries"]["minjust_foreign_agents"]
if meta["status"] != "ok":
    raise SystemExit("реестр не снят — это «данных нет», а не «записей нет»")
data = json.loads(urllib.request.urlopen(BASE + meta["file"]).read())
for entry in data["entries"]:
    ...
```

### Схема записи

```json
{"id": "...", "kind": "person|org|material", "name": "как в первоисточнике",
 "aliases": ["короткие названия для поиска"], "inn": null, "ogrn": null,
 "included_at": "дата включения", "decision": "решение суда", "raw": {}}
```

`name` сохраняется ровно как в первоисточнике — именно это значение
подставляется в обязательную плашку при упоминании.

## Свежесть: читайте обязательно

У каждого реестра в манифесте есть `freshness_window_days` — срок, в течение
которого копию ещё можно считать пригодной для вывода «упоминаний не найдено».

| Реестр | Окно | Почему столько |
|--------|------|----------------|
| Иностранные агенты | 10 дней | Пополняется еженедельно, обычно по пятницам |
| Нежелательные организации | 30 дней | Пополняется нерегулярно |
| Экстремистские материалы | 30 дней | |
| Экстремистские организации | 45 дней | Меняется раз в месяцы |
| Террористические организации | 45 дней | |

**Просроченная копия не даёт права утверждать, что упоминаний нет.** Она даёт
право сказать «проверить не удалось». Разница принципиальная: ложное «всё
чисто» по списку, в котором нужного лица ещё нет, хуже честного отказа — по
нему человек ничего не сделает и получит штраф.

Если реестр снять не удалось, в манифесте у него `status: "failed"` и
`last_error`. Трактовать это как пустой список нельзя.

## Чем это не является

Это **не официальная публикация**. Официальные публикации — на сайтах Минюста
и ФСБ, ссылки в `source_url`. Здесь их производная копия, снятая
автоматически, без юридической силы и без гарантий полноты или актуальности.

Ошибка разбора, сбой сети или изменение формата выгрузки могут привести к
неполным данным. Для юридически значимых решений сверяйтесь с первоисточником.

## Как это устроено

`update.py` запускается по расписанию, снимает каждый реестр с официального
источника, нормализует и пишет в `data/`. Файл переписывается только если
содержимое изменилось — иначе в истории копились бы пустые коммиты.

Зеркала здесь не публикуются принципиально: зеркалить чужое зеркало
бессмысленно, цепочка происхождения теряется.

Разбор форматов не продублирован — используется `registries.py` из скилла
[pepper-ru-web-compliance](https://github.com/ITSalt/PepperSkills). Две
расходящиеся реализации парсинга одних и тех же кривых выгрузок гарантированно
разъехались бы.

Записи пишутся по одной в строку. Файл остаётся валидным JSON, но git хранит
построчные диффы: иначе еженедельный коммит четырёхмегабайтного реестра
переписывал бы файл целиком и репозиторий разнесло бы за год.

Развёртывание — [`deploy/README.md`](./deploy/README.md).
